1Kenali struktur project

Aplikasi menggunakan JavaScript module native di browser. Setiap file punya satu tanggung jawab supaya alur program lebih mudah dipresentasikan.

  • index.html: struktur halaman dan CDN Vue, Supabase, Bootstrap.
  • style.css: tampilan dashboard dan komponen.
  • app.js: menghubungkan modul dan memasang aplikasi Vue.
  • supabase.js: URL, public key, dan Supabase client.
  • auth.js: login, daftar, validasi form, sesi, serta profil dan role.
  • inventory.js: mengambil dan mengubah data barang.
  • docs/index.html: halaman dokumentasi yang sedang dibuka.
Contoh di halaman ini adalah potongan pembelajaran. File project yang sudah ada menggabungkan potongan-potongan ini ke dalam modul.

2Buat project Supabase dan tabel

  1. Buat project di supabase.com.
  2. Buka SQL Editor → New query, tempel SQL di bawah, lalu tekan Run.
  3. SQL membuat tabel profil/barang, membuat profil otomatis saat user mendaftar, dan membatasi akses melalui RLS.
SQL · jalankan di Supabase SQL Editor
create table if not exists public.profiles (
    id uuid primary key references auth.users(id) on delete cascade,
    full_name text,
    role text not null default 'user' check (role in ('admin', 'user')),
    created_at timestamptz not null default now()
);

create table if not exists public.items (
    id uuid primary key default gen_random_uuid(),
    name text not null,
    category text not null,
    stock integer not null default 0 check (stock >= 0),
    unit text not null,
    created_at timestamptz not null default now()
);

/* Profil baru otomatis dibuat ketika akun Auth berhasil mendaftar. */
create or replace function public.handle_new_user()
returns trigger
language plpgsql
security definer
set search_path = public, pg_temp
as $$
begin
    insert into public.profiles (id, full_name, role)
    values (
        new.id,
        coalesce(new.raw_user_meta_data ->> 'full_name', new.email),
        'user'
    )
    on conflict (id) do update
        set full_name = excluded.full_name;
    return new;
end;
$$;

drop trigger if exists on_auth_user_created on auth.users;
create trigger on_auth_user_created
after insert on auth.users
for each row execute function public.handle_new_user();

/* Role diperiksa di database; menyembunyikan tombol di UI saja bukan keamanan. */
create or replace function public.current_user_role()
returns text
language sql
stable
security definer
set search_path = public, pg_temp
as $$
    select p.role from public.profiles p where p.id = auth.uid()
$$;

revoke all on function public.current_user_role() from public;
grant execute on function public.current_user_role() to authenticated;
grant usage on schema public to authenticated;
grant select on public.profiles to authenticated;
grant select, insert, update, delete on public.items to authenticated;

alter table public.profiles enable row level security;
alter table public.items enable row level security;

drop policy if exists "profiles_read_own" on public.profiles;
create policy "profiles_read_own"
on public.profiles for select to authenticated
using (id = auth.uid());

drop policy if exists "items_read_authenticated" on public.items;
create policy "items_read_authenticated"
on public.items for select to authenticated
using (true);

drop policy if exists "items_insert_admin" on public.items;
create policy "items_insert_admin"
on public.items for insert to authenticated
with check (public.current_user_role() = 'admin');

drop policy if exists "items_update_admin" on public.items;
create policy "items_update_admin"
on public.items for update to authenticated
using (public.current_user_role() = 'admin')
with check (public.current_user_role() = 'admin');

drop policy if exists "items_delete_admin" on public.items;
create policy "items_delete_admin"
on public.items for delete to authenticated
using (public.current_user_role() = 'admin');
Penting: RLS harus aktif. Admin dapat mengelola barang, sedangkan semua user yang sudah login hanya dapat membaca barang. Profil hanya dapat dibaca oleh pemilik akun.

3Hubungkan aplikasi ke Supabase

  1. Di dashboard Supabase, buka Project Settings → API (atau bagian API keys).
  2. Salin Project URL dan publishable key (atau anon key lama).
  3. Ganti nilai contoh pada supabase.js.
JavaScript · supabase.js
// Publishable/anon key boleh digunakan di browser jika RLS sudah benar.
// Jangan gunakan service_role key di frontend.
const SUPABASE_URL = 'https://PROJECT-ID.supabase.co';
const SUPABASE_ANON_KEY = 'PASTE_PUBLISHABLE_OR_ANON_KEY_HERE';

const supabaseClient = window.supabase.createClient(
    SUPABASE_URL,
    SUPABASE_ANON_KEY
);

Key frontend bukan pengganti akses kontrol. Perlindungan database harus datang dari RLS dan kebijakan yang benar.

4Contoh autentikasi

Daftar akun

JavaScript · Auth signup
const { data, error } = await supabaseClient.auth.signUp({
    email: 'siswa@example.com',
    password: 'password-yang-kuat',
    options: {
        data: { full_name: 'Nama Siswa' }
    }
});

if (error) {
    console.error('Pendaftaran gagal:', error.message);
} else if (!data.session) {
    // Jika konfirmasi email aktif, user perlu konfirmasi sebelum login.
    console.log('Periksa email untuk konfirmasi akun.');
} else {
    console.log('Akun berhasil dibuat.');
}

Login, session persistence, dan logout

JavaScript · Auth session
const { data, error } = await supabaseClient.auth.signInWithPassword({
    email: 'siswa@example.com',
    password: 'password-yang-kuat'
});

if (error) {
    console.error('Login gagal:', error.message);
} else {
    console.log('User aktif:', data.user.email);
}

// Supabase menyimpan sesi di browser. Periksa sesi ketika aplikasi dibuka.
const { data: sessionData } = await supabaseClient.auth.getSession();
console.log('Sesi aktif:', Boolean(sessionData.session));

// Logout
const { error: logoutError } = await supabaseClient.auth.signOut();
if (logoutError) console.error('Logout gagal:', logoutError.message);

Validasi form sebelum memanggil Supabase

Form diperiksa lebih dulu agar request yang pasti gagal tidak dikirim ke server.

JavaScript · validasi form
const { fullName, email, password } = authForm.value;

if (!email.trim() || !password) {
    authError.value = 'Email dan kata sandi wajib diisi.';
    return;
}
if (authMode.value === 'register') {
    if (!fullName.trim()) {
        authError.value = 'Nama lengkap wajib diisi.';
        return;
    }
    if (password.length < 6) {
        authError.value = 'Kata sandi minimal 6 karakter.';
        return;
    }
}

Alur modul auth.js

  1. Saat aplikasi dibuka, getSession() memeriksa sesi yang tersimpan.
  2. loadUserData() mengambil full_name dan role dari tabel profiles.
  3. Jika berhasil, onAuthenticated() dipanggil. Jika profil gagal dimuat atau user keluar, onSignedOut() dipanggil agar data sesi sebelumnya tidak tertinggal.
  4. onAuthStateChange memantau login dan logout berikutnya.
  5. Saat komponen dilepas, listener dihentikan dengan unsubscribe(). Flag unmounted mencegah listener terdaftar setelah itu.
loadRequestId memastikan hanya permintaan profil terbaru yang dipakai, sehingga respons lama tidak menimpa data baru.

5Contoh CRUD inventaris

Semua operasi database menggunakan async/await. RLS tetap memeriksa role saat request sampai ke Supabase.

Read: membaca barang

JavaScript · SELECT
async function loadItems() {
    const { data, error } = await supabaseClient
        .from('items')
        .select('id, name, category, stock, unit, created_at')
        .order('created_at', { ascending: false });

    if (error) {
        console.error('Gagal memuat barang:', error.message);
        return [];
    }
    return data;
}

Create: menambahkan barang

JavaScript · INSERT (khusus admin)
const barangBaru = {
    name: 'Kertas A4',
    category: 'ATK',
    stock: 25,
    unit: 'rim'
};

const { error } = await supabaseClient
    .from('items')
    .insert(barangBaru);

if (error) console.error('Gagal menambah barang:', error.message);

Update dan Delete: mengubah atau menghapus barang

JavaScript · UPDATE & DELETE (khusus admin)
// Update: selalu gunakan .eq() untuk menentukan barang yang diubah.
const { error: updateError } = await supabaseClient
    .from('items')
    .update({ stock: 30 })
    .eq('id', itemId);

// Delete: pastikan id barang spesifik sebelum menghapus.
const { error: deleteError } = await supabaseClient
    .from('items')
    .delete()
    .eq('id', itemId);

if (updateError || deleteError) {
    console.error('Operasi gagal:', updateError?.message || deleteError?.message);
}

6Konsep Vue 3 yang digunakan

ref() menyimpan state reaktif. computed() menghitung nilai dari state; UI diperbarui ketika datanya berubah.

JavaScript · Composition API
const { ref, computed } = Vue;

const items = ref([]);
const searchQuery = ref('');

const filteredItems = computed(() => {
    const query = searchQuery.value.toLowerCase();
    return items.value.filter(item =>
        item.name.toLowerCase().includes(query)
    );
});

const totalStock = computed(() =>
    items.value.reduce((sum, item) => sum + Number(item.stock), 0)
);
HTML · binding Vue
<input v-model="searchQuery" placeholder="Cari barang...">

<ul>
    <li v-for="item in filteredItems" :key="item.id">
        {{ item.name }}: {{ item.stock }} {{ item.unit }}
    </li>
</ul>

<p>Total stok: {{ totalStock }}</p>

7Membuat akun admin pertama

  1. Daftar akun dari halaman aplikasi. Trigger SQL akan membuat profil baru dengan role user.
  2. Di Supabase SQL Editor, jalankan query berikut dan ganti email contoh dengan email akun Anda.
  3. Keluar lalu masuk kembali agar aplikasi memuat role terbaru.
SQL · jadikan admin
update public.profiles
set role = 'admin'
where id = (
    select id
    from auth.users
    where email = 'email-admin-anda@example.com'
);
Jangan membuka pendaftaran role admin dari browser. Role awal ditetapkan database sebagai user; perubahan role dilakukan oleh operator tepercaya di Supabase.

9Jika ada masalah

  • Login gagal: cek email/password, konfirmasi email, URL, dan public key Supabase.
  • Muncul "Email dan kata sandi wajib diisi" atau "Kata sandi minimal 6 karakter": ini validasi form di aplikasi, bukan error Supabase. Lengkapi form sesuai aturan.
  • Langsung keluar setelah login: profil gagal dimuat, sehingga onSignedOut() dipanggil. Cek tabel profiles, trigger on_auth_user_created, dan policy profiles_read_own.
  • Profil belum tersedia: pastikan trigger on_auth_user_created sudah dibuat; akun yang dibuat sebelum trigger mungkin perlu dibuat ulang atau profilnya dibuat dengan aman.
  • Tidak bisa menambah atau mengedit barang: cek kolom profiles.role dan pastikan role akun admin.
  • Permintaan ditolak Supabase: cek RLS, policy, dan grant tabel. Jangan mematikan RLS untuk mengatasi masalah.
  • Modul tidak ditemukan: jalankan lewat Live Server, bukan membuka file HTML dengan file://.
